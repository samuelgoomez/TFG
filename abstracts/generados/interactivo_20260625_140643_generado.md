This paper presents an automated code review recommendation system designed to address the inefficiencies and inconsistencies of manual code reviews, which can be time-consuming and subject to varying reviewer perspectives. The system evaluates pull requests by identifying and categorizing issues related to code quality, security vulnerabilities, and style violations. Utilizing a dataset of 50,000 real pull requests from GitHub, particularly from Python and Java projects, it includes a manually labeled subset of 5,000. The methodology involves fine-tuning the CodeBERT model to establish a multi-label classification architecture, followed by comprehensive evaluation using precision, recall, and F1 score metrics across categories, alongside user studies with twelve developers. Results reveal an F1 score of 0.87 for code quality issues, 0.79 for security vulnerabilities, and 0.91 for style violations, with system feedback rated as comparable or superior to that of junior human reviewers in 73% of cases. Additionally, the system achieved a 34% reduction in review time, surpassing the target of 30%. These findings indicate that CodeBERT can effectively function as a reliable assistant in real-world code review contexts, reducing cognitive load while maintaining quality, and contributes a publicly accessible labeled dataset of 5,000 pull requests to the community.
